Fitness Tracker Application

Project Overview
  A desktop fitness tracking application developed in C# that enables users to monitor their fitness activities, set calorie-burning goals, and track their progress across multiple exercise types.

Features:

1.	User Authentication

    Account registration with username (letters and numbers only) and password (12 characters, at least 1 uppercase and 1 lowercase letter)
  Secure login system with failed attempt handling
  User-specific goal tracking and activity history

2.	Goal Setting:

    Set personalized calorie-burning targets
    Goals linked to user accounts for persistence

3.	Activity Tracking:
    Supports tracking of 6 different fitness activities:

      •	Walking - Steps, Distance, Time taken
      
      •	Swimming - Number of laps, Time taken, Average heart rate
      
      •	Running - Distance, Time taken, Average pace
      
      •	Cycling - Distance, Time taken, Average speed
      
      •	Yoga - Duration, Intensity level, Heart rate
      
      •	Weightlifting - Duration, Weight lifted, Number of repetitions

4.	Progress Monitoring:

      •	Automatic calorie calculation based on activity metrics
      
      •	Total calories burned tracking
      
      •	Goal achievement reporting

5.	Technical Requirements:

    Language: C#
    
    IDE: Visual Studio 2019/2022 or Visual Studio Code
    
    UI Framework: Windows Forms or WPF
    
    .NET: Framework 4.7.2+ or .NET 6.0+
